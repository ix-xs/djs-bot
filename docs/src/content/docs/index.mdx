## From this, to this

<Tabs>
  <TabItem label="A command">
    ```ts
    import { defineCommand, s } from "@ix-xs/djs-bot";

    export default defineCommand({
      name: "profile",
      description: "Show a player profile",
      options: {
        user: s.user({ description: "Whose profile", required: true }),
      },
      run: (ctx) => ctx.reply.success(`Profile of ${ctx.options.user}`),
      //                                   ctx.options.user is a User, never undefined
    });
    ```
    <DiscordMessage author="djs-bot">
      <DiscordEmbed color="#23a55a" description="✅ Profile of @Alice" />
    </DiscordMessage>
  </TabItem>
  <TabItem label="A button">
    ```ts
    import { defineButton, p, ButtonStyle } from "@ix-xs/djs-bot";

    export const CloseTicket = defineButton({
      id: "ticket:close",
      params: { ticketId: p.string, ownerId: p.string },
      run: async (ctx) => {
        // ctx.params is decoded and fully typed - no split("_")
        if (ctx.user.id !== ctx.params.ownerId) return void ctx.reply.error("Not your ticket.");
        await ctx.update.disable();
      },
    });
    ```
    <DiscordMessage author="djs-bot" content="🎫 <strong>Printer is on fire</strong>">
      <DiscordButtons buttons={[{ label: "Close ticket", style: "danger", emoji: "🔒" }]} />
    </DiscordMessage>
  </TabItem>
  <TabItem label="An event">
    ```ts
    import { defineEvent } from "@ix-xs/djs-bot";

    export default defineEvent("guildMemberAdd", async (member, ctx) => {
      // The GuildMembers intent is enabled automatically because of this line
      await member.guild.systemChannel?.send(`Welcome ${member}! 👋`);
    });
    ```
    <DiscordMessage author="djs-bot" content="Welcome @NewUser! 👋" />
  </TabItem>
  <TabItem label="A form">
    ```ts
    import { defineModal, field } from "@ix-xs/djs-bot";

    export const Report = defineModal({
      id: "report",
      title: "Report a problem",
      fields: {
        kind: field.select({ label: "Kind", required: true, options: [{ label: "Bug", value: "bug" }] }),
        details: field.paragraph({ label: "Details", maxLength: 1000 }),
        proof: field.files({ label: "Screenshots", maxValues: 3 }),
        urgent: field.checkbox({ label: "This is urgent" }),
      },
      // ctx.fields: { kind: string[]; details: string; proof: Collection<...>; urgent: boolean }
      run: (ctx) => ctx.reply.success(`Reported (${ctx.fields.proof.size} file(s)).`),
    });

    // from any command or button:  await ctx.showModal(Report);
    ```
    <DiscordMessage author="djs-bot">
      <DiscordEmbed color="#23a55a" description="✅ Reported (2 file(s))." />
    </DiscordMessage>
  </TabItem>
</Tabs>

## Why djs-bot

<CardGrid stagger>
  <Card title="Type-safe end to end" icon="approve-check">
    Typed slash options, typed `customId` params, typed services and config. `required: true` makes an option non-optional - no casts, no `any`.
  </Card>
  <Card title="No magic" icon="setting">
    Files export `define*()` objects; nothing registers by importing. `djs-bot explain` shows exactly what's loaded and why.
  </Card>
  <Card title="Production-ready" icon="rocket">
    Error boundaries, graceful shutdown, structured logs, sharding, health checks and Prometheus metrics, persistence with atomic counters, rate limiting - built in.
  </Card>
  <Card title="Batteries included" icon="puzzle">
    Subcommands, context menus, autocomplete, native selects, modern modals, triggers, pagination, `confirm()`, polls, presence, assets, voice - and official plugins.
  </Card>
  <Card title="Never 'interaction failed'" icon="seti:clock">
    Turn on automatic deferral once and slow handlers are acknowledged for you, without ever colliding with your own reply.
  </Card>
  <Card title="Speaks your language" icon="translate">
    Localized command names, per-user translations with `ctx.t()`, and every sentence the framework itself says can be reworded or translated.
  </Card>
</CardGrid>

## Get started in 60 seconds

```bash
npm install @ix-xs/djs-bot discord.js
npx djs-bot init      # scaffold a working starter
npx djs-bot dev       # watch + instant deploy to your test server
```

<Aside type="tip" title="Never built a bot before?">
The [tutorial](/tutorial/what-you-need/) walks you through everything -
creating the app on Discord, getting your token, inviting the bot, your first
command, buttons, and putting it online. No prior experience assumed.
</Aside>
