This guide teaches you how to build a Discord bot with **djs-bot**, from
installation to putting it online. Each step tells you **what to do** and
**why**.

## What djs-bot is

A Discord bot is a program that connects to Discord. Discord sends it what
is happening ("someone typed `/ping`"), and the program responds.

To talk to Discord from Node.js, you use
[discord.js](https://discord.js.org). But discord.js leaves all the wiring to
you: sorting every interaction you receive, presenting your commands to
Discord, choosing the events to listen to, checking every option.

**djs-bot does that wiring for you.** You write one file per thing the bot
does, and that's it:

```ts title="src/features/ping/ping.command.ts"
import { defineCommand } from "@ix-xs/djs-bot";

export default defineCommand({
  name: "ping",
  description: "Check the bot is alive",
  run: (ctx) => ctx.reply.success("Pong! 🏓"),
});
```

No list to keep up to date, no registration script: the file exists, so the

## What you will build

A single bot, page after page:

1. **Getting started**: the application on Discord, then the project on your
   computer.
2. **Your bot**: the configuration, starting it, a first command, events,
   then putting it online.
3. **Going further**: buttons, menus, forms, data, production. Read these
   when you need them.

The [reference](/reference/) describes every function and every type in the
package.

## What you should know first

- **The basics of JavaScript**: functions, objects, `import`, `async`/`await`.
- **How to open a terminal** in a folder and type a command there.

You do not need to know discord.js or TypeScript. The guide uses TypeScript
(your editor then spots mistakes before the bot starts), but everything also
works in JavaScript: just leave the types out.

<Aside type="tip" title="Already know discord.js?">
Everything still applies: `ctx.interaction`, `ctx.guild` or `ctx.client` are
the real discord.js objects.
</Aside>
