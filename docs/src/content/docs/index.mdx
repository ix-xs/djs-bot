  <header><span>01</span><h2>One file, one feature</h2></header>
  <p>A file exports a definition. The framework finds it, registers it with Discord, routes the interaction to it and hands you typed values. There is no registration code to write and nothing to keep in sync.</p>

  <Tabs>
    <TabItem label="A command">
      ```ts title="features/profile/profile.command.ts"
      import { defineCommand, s } from "@ix-xs/djs-bot";

      export default defineCommand({
        name: "profile",
        description: "Show a player profile",
        options: {
          user: s.user({ description: "Whose profile", required: true }),
        },
        // ctx.options.user is a User, never undefined
        run: (ctx) => ctx.reply.success(`Profile of ${ctx.options.user}`),
      });
      ```
      <DiscordMessage caption="Result in Discord" used={{ user: "Jo", command: "profile" }}>

    <TabItem label="An event">
      ```ts title="features/welcome/welcome.event.ts"
      import { defineEvent } from "@ix-xs/djs-bot";

      // The GuildMembers intent is switched on because this listener exists.
      export default defineEvent("guildMemberAdd", async (member) => {
        await member.guild.systemChannel?.send(`Welcome ${member}!`);
      });
      ```
      <DiscordMessage caption="Result in Discord" content="Welcome @Jo!" />

    <TabItem label="A form">
      ```ts title="features/report/report.modal.ts"
      import { defineModal, field } from "@ix-xs/djs-bot";

      export const Report = defineModal({
        id: "report",
        title: "Report a problem",
        fields: {
          kind: field.select({ label: "Kind", required: true, options: [{ label: "Bug", value: "bug" }] }),
          details: field.paragraph({ label: "Details", maxLength: 1000 }),
          proof: field.files({ label: "Screenshots", maxValues: 3 }),
          urgent: field.checkbox({ label: "This is urgent" }),
        },
        // ctx.fields: { kind: string[]; details: string; proof: Collection<...>; urgent: boolean }
        run: (ctx) => ctx.reply.success(`Reported, with ${ctx.fields.proof.size} file(s).`),
      });
      ```

      import { defineJob } from "@ix-xs/djs-bot";

      export default defineJob({
        name: "daily-stats",
        schedule: "@daily",
        run: async (ctx) => {
          const guilds = ctx.client.guilds.cache.size;
          await ctx.services.store.set("stats:guilds", guilds);
          ctx.logger.info({ guilds }, "daily stats saved");

<section class="at-section">
  <header><span>02</span><h2>What you stop writing</h2></header>
  <ul class="at-points">
    <li><h3>Casts and null checks</h3><p>Options, customId params, modal fields, services and config are typed from their declaration. <code>required: true</code> makes the value non-optional.</p></li>
    <li><h3>Registration and intents</h3><p>Commands are diffed and deployed for you, and the gateway intents are derived from the events you listen to.</p></li>
    <li><h3>"The application did not respond"</h3><p>Turn on automatic deferral once. A slow handler is acknowledged for you, and it never collides with your own reply.</p></li>
    <li><h3>String parsing in buttons</h3><p>A button carries typed data in its customId. The click comes back to your handler decoded, with no <code>split("_")</code>.</p></li>
    <li><h3>The production checklist</h3><p>Error boundary, graceful shutdown, structured logs, sharding, health checks, metrics, rate limits and a store with atomic counters are built in.</p></li>
    <li><h3>A test server for every change</h3><p>Handlers are plain functions. The harness runs a command, a button or a form and captures the reply, with no token and no network.</p></li>
  </ul>
</section>
