`/server` et `/user` sont apparues sans être « branchées » nulle part. Voici
comment, et ce que ça change pour ranger votre projet.

## Le problème que ça résout

Dans un bot discord.js écrit à la main, ajouter une commande demande de
toucher plusieurs endroits : le fichier, une liste qui les regroupe, le code
qui appelle la bonne, le script qui les envoie à Discord. En oublier un, c'est
une commande qui n'apparaît pas. Avec djs-bot, il ne reste que **le fichier**.

## Le nom du fichier sert à le trouver

Au démarrage, le bot parcourt `features` et ses sous-dossiers, et charge
chaque fichier qui se termine par l'un de ces suffixes :

| Suffixe | Contient |
| --- | --- |
| `.command.ts` | une commande slash |
| `.user.ts` / `.message.ts` | une action du clic droit sur un membre / un message |
| `.button.ts` | un bouton |
| `.select.ts` | un menu de sélection |
| `.modal.ts` | un formulaire |
| `.event.ts` | un écouteur d'événement |
| `.trigger.ts` | une réponse automatique à un message |
| `.job.ts` | une tâche planifiée |
| `.service.ts` | un service partagé |
| `.plugin.ts` / `.feature.ts` | un plugin / une fonctionnalité regroupée |

`.js`, `.mjs` et `.cjs` marchent aussi. Tout le reste est ignoré (`utils.ts`,
`ping.command.test.ts`, les `.d.ts`) : rangez votre code d'aide à côté sans
crainte.

## La fonction `define` dit ce que c'est

Le suffixe sert à **trouver** le fichier. C'est la fonction `define...`
utilisée qui dit ce qu'il contient, et un fichier peut en exporter plusieurs :

```ts title="src/features/tickets/ticket.command.ts"
import { defineButton, defineCommand, ui } from "@ix-xs/djs-bot";

// A button, declared in the same file as the command: it is loaded too.
export const close = defineButton({
  id: "ticket-close",
  label: "Close",
  run: (ctx) => ctx.update({ content: "Ticket closed.", components: [] }),
});

export default defineCommand({
  name: "ticket",
  description: "Open a support ticket",
  run: (ctx) => ctx.reply({ content: "Ticket opened.", components: [ui.row(close.build())] }),
});
```

Importer un fichier ne déclenche rien : il ne fait que **décrire**. C'est ce
qui permet aux outils de lire le bot sans le connecter.

## Ranger un projet qui grandit

L'emplacement n'a pas d'importance pour le bot : rangez pour les humains,
**un dossier par fonctionnalité**.

<FileTree>
- src/
  - index.ts
  - features/
    - ping/
      - ping.command.ts
    - info/
      - server.command.ts
      - user.command.ts
    - tickets/
      - ticket.command.ts      ouvre un ticket
      - close.button.ts        le ferme
      - tickets.service.ts     les enregistre
      - format.ts              du code d'aide, ignoré
    - welcome/
      - welcome.event.ts
</FileTree>

Où est le code des tickets ? Dans `tickets/`. Retirer la fonctionnalité ?
Supprimer le dossier.

Une commande n'apparaît pas ? Vérifiez d'abord que le bot l'a trouvée :

invisible dans Discord : voyez la page suivante.
