Ce guide vous apprend à créer un bot Discord avec **djs-bot**, de
l'installation jusqu'à la mise en ligne. Chaque étape dit **quoi faire** et
**pourquoi**.

## Ce qu'est djs-bot

Un bot Discord est un programme qui se connecte à Discord. Discord lui envoie
ce qui se passe (« quelqu'un a tapé `/ping` »), le programme répond.

Pour parler à Discord depuis Node.js, on utilise
[discord.js](https://discord.js.org). Mais discord.js vous laisse tout câbler
à la main : trier chaque interaction reçue, présenter les commandes à
Discord, choisir les événements à écouter, vérifier chaque option.

**djs-bot fait ce câblage pour vous.** Vous écrivez un fichier par chose que
fait le bot, et c'est tout :

```ts title="src/features/ping/ping.command.ts"
import { defineCommand } from "@ix-xs/djs-bot";

export default defineCommand({
  name: "ping",
  description: "Check the bot is alive",
  run: (ctx) => ctx.reply.success("Pong! 🏓"),
});
```

## Ce que vous allez construire

Un seul bot, page après page :

1. **Pour commencer** : l'application sur Discord, puis le projet sur votre
   ordinateur.
2. **Votre bot** : la configuration, le lancement, une première commande,
   les événements, puis la mise en ligne.
3. **La suite** : boutons, menus, formulaires, données, production. À lire
   quand vous en avez besoin.

La [référence](/reference/) décrit chaque fonction et chaque type du paquet.

## Ce qu'il faut savoir avant

- **Les bases de JavaScript** : fonctions, objets, `import`, `async`/`await`.
- **Ouvrir un terminal** dans un dossier et y taper une commande.

Inutile de connaître discord.js ou TypeScript. Le guide utilise TypeScript
(votre éditeur repère alors les erreurs avant le lancement), mais tout
marche aussi en JavaScript : il suffit de retirer les types.

<Aside type="tip" title="Vous connaissez déjà discord.js ?">
Tout reste valable : `ctx.interaction`, `ctx.guild` ou `ctx.client` sont les
vrais objets de discord.js.
</Aside>
