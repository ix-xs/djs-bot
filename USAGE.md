# @ix-xs/djs-bot - documentation

The documentation lives at **https://ix-xs.github.io/djs-bot/**, one page per topic. This file is its
table of contents, so that the package you installed tells you where to look.

Every function, option and `ctx` property also carries a description in your
editor: hover a name, or ask for completions inside a `define*()` call.
