# Security policy

## Supported versions

The latest `1.x` release on npm receives security fixes.

| Version | Supported |
| --- | --- |
| 1.x | ✅ |
| < 1.0 (beta) | ❌ |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately via GitHub's [security advisories](https://github.com/ix-xs/djs-bot/security/advisories/new),
or email **contact@ix-xs.dev**. Include a description, affected versions, and a
minimal reproduction if possible.

You'll get an acknowledgement, and a fix will be released as promptly as the
severity warrants, with credit unless you prefer to remain anonymous.
